# AGENTS.md

Entry point for AI coding agents working in this repo. Read this first, then the files it points to.

## What this is

A single-page, dependency-free interactive timeline of 44 world religions.

- **Content:** `data/religions.json`.
- **The page:** `src/template.html`.
- **The build:** `scripts/build.mjs` inlines the data into the template and writes the artifact fragment (`dist/`) and the standalone `index.html`.

There is no framework, no bundler and no npm dependency.

## Read before changing anything

- [AI/README.md](AI/README.md): map of the AI docs and the reading order.
- [AI/ARCHITECTURE.md](AI/ARCHITECTURE.md): how the page is built (data → layout → SVG → interaction).
- [AI/decisions/](AI/decisions/): why it is built this way. Don't undo a decision without writing a new ADR that supersedes it.

- [AI/CONTENT-GUIDE.md](AI/CONTENT-GUIDE.md): tone, sourcing and placement rules for the text.

## Rules that always apply

1. **Edit `data/religions.json` and `src/template.html`.** Never edit `index.html` or `dist/`; they are generated by `npm run build`.
2. **Keep the template a self-contained artifact fragment** ([ADR 0001](AI/decisions/0001-single-self-contained-html-page.md), [ADR 0012](AI/decisions/0012-data-in-json-inlined-at-build.md)):
	- `<title>` first;
	- no `<!doctype>`, `<html>`, `<head>` or `<body>` tags;
	- inline CSS and JS;
	- the `/*@DATA@*/null` and `/*@NOTES@*/null` markers exactly once each;
	- external loads only from Google Fonts, and no `fetch`.
3. **No libraries or build frameworks** ([ADR 0002](AI/decisions/0002-vanilla-js-and-hand-built-svg.md)).
4. **Colour carries no category on its own** ([ADR 0005](AI/decisions/0005-focus-and-context-instead-of-family-colours.md)). Every colour is a token: define it on the bare `:root` (Night) and in **both** Day blocks ([ADR 0013](AI/decisions/0013-night-and-day-themes.md)).
5. **Content stays neutral and sourced** ([CONTENT-GUIDE](AI/CONTENT-GUIDE.md)):
	- attribute beliefs ("tradition holds…", "historians date…");
	- never present a miracle or revelation as fact;
	- never invent quotes, numbers or sources.
6. **This repo is public.** Never add personal information: names, emails, home-directory paths, private URLs, tokens, or notes from anyone's personal systems. Private notes links exist only in builds written outside the repo ([ADR 0015](AI/decisions/0015-private-notes-links-outside-the-repo.md)).
7. **Before calling a change done:**
	- run `npm run validate && npm run build && npm test`;
	- if links changed, run `npm run links`;
	- for a visual change, render the page and look at it at desktop and phone widths, in Night and Day.
8. **Record changes.** Add a line to `CHANGELOG.md`, and an ADR in `AI/decisions/` for any design or architecture change.
